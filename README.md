1.6. Задачи на нахождение суммарных значений

Составить программу для вычисления в цикле суммарного результата.

24. Найти суммарную площадь для N равнобедренных треугольников,
имеющих одинаковое основание A, но различные длины боковых сторон,
образующие прогрессию A + 1, A + 2, A + 3, ..., A + N.
